01 / INSTALL

Get a working binary in minutes.

ContextGC currently builds from source with stable Rust. The install path is intentionally transparent: clone, compile, run.

01

Install prerequisites

You need Git and the latest stable Rust toolchain.

# macOS xcode-select --install curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

On Linux, install your distribution's build tools first, then run the Rustup command.

02

Clone and compile

Clone the repository and build the optimized workspace.

git clone https://github.com/wuisabel-gif/ContextGC.git cd ContextGC cargo build --release --workspace
03

Put contextgc on your PATH

This makes the command available from any project directory.

mkdir -p ~/.local/bin install -m 755 target/release/contextgc ~/.local/bin/contextgc # Start a new shell if ~/.local/bin is not on your PATH yet.
04

Verify the install

contextgc --help

✓ You should see the ingest, status, plan, compact, stats, and protocol commands.

Build directly from a checkout

If you already have the source, the only command you need is:

cargo build --release --workspace

The binary is written to target/release/contextgc. For development, use cargo test --workspace and cargo run -p contextgc-cli -- --help.

03 / HOW IT WORKS

Context is managed as a working set.

Deterministic Rust logic handles the critical path. Semantic compression can be added later without making it mandatory.

01

Observe

Every message, file read, tool result, error, diff, and checkpoint becomes a typed context object with token accounting and provenance.

02

Predict

Exponential moving averages estimate the next tool result and assistant continuation before an autonomous loop overflows.

03

Decide

Importance, recency, dependency, authority, uniqueness, recoverability, and redundancy produce an explainable plan.

04

Materialize

The least destructive actions are applied until the target budget is safe: deduplicate, reduce, extract, externalize, or evict.

least destructive KEEP→DEDUPLICATE→REDUCE→EXTRACT→EXTERNALIZE→EVICTmore reclaim
